Privacy Policy

Axian Uploader · last updated 29 October 2026

This tool uses YouTube API Services. By using it, the user agrees to be bound by the YouTube Terms of Service. Information obtained through YouTube API Services is also handled under the Google Privacy Policy.

Who uses this tool

Axian Uploader is a private, non-commercial tool. It is used only by its owner (the operator of the "Axian Animasi" / "阿贤音乐库" channels) to publish the owner's own original videos to the owner's own accounts. It is not available to the public and has no other users.

What data it accesses

  • YouTube (Google): permission to upload videos to the owner's channel (youtube.upload), to read the owner's channel and video details (youtube.readonly), and to read the owner's own channel analytics such as views and audience retention (yt-analytics.readonly).
  • Instagram / Facebook (Meta): permission to publish Reels to the owner's Instagram professional account and to read basic information about the owner's linked Facebook Page.

The tool does not access any other person's account or data.

How the data is used

Access is used only to upload the owner's finished videos with their titles and descriptions at a scheduled time, and to read the owner's own video statistics to decide how to improve future videos. Nothing else.

Storage

Access tokens are stored only on the owner's personal computer, in local files that are not shared. Video statistics are kept in local notes on the same computer. No data is stored on any server operated by this tool.

Sharing

No data is sold, rented, shared with third parties, or used for advertising. Data obtained through Google APIs is not transferred to anyone.

Google API Services

Axian Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Uploads made through the YouTube API are also subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions (Google Account → Security → Third-party apps with account access), and from Facebook → Settings → Business integrations. Revoking access immediately stops all uploads and data reads.

Data retention and deletion

The tool keeps only (1) the OAuth tokens and (2) weekly statistics summaries, both on the owner's computer. Statistics summaries are refreshed weekly and are never kept for more than 30 days without being updated or deleted. When access is revoked, the local token files and stored statistics are deleted within 7 days. To request deletion of any data, or to ask a question, email zhengmaimai0@gmail.com; requests are completed within 7 days.
